批量水印工具 - 源码说明
========================

一、环境要求
------------
- Windows 10 / 11，64 位
- Python 3.10 及以上（开发和测试使用 3.12.14）
- 不需要显卡，不需要联网，不调用任何 AI 接口

二、安装依赖
------------
在本目录打开命令行，执行：

    python -m pip install -r requirements.txt

如果下载慢，可使用国内镜像，例如：

    python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

三、直接运行源码
----------------
    python app.py

或双击“运行.bat”。

四、重新打包成 exe
------------------
双击“打包.bat”，或在命令行执行：

    python -m pip install "pyinstaller==6.22.3"
    python -m PyInstaller --noconfirm --clean --windowed --name "批量水印工具" --distpath "发布" --workpath "build" app.py

打包结果在“发布\批量水印工具\”下。
这是 PyInstaller 的 one-folder 模式，必须保留 exe 旁边的 _internal 文件夹，
不能只拷贝 exe。

五、文件说明
------------
app.py
    Tkinter 图形界面：文件夹选择、样图加载、选区绘制、预览、批量任务、
    进度/日志/取消、加水印参数、输出目录控制。

core.py
    图像算法核心：
    - cv_imread / cv_imwrite：兼容中文路径的 OpenCV 读写
    - build_mask / mask_bbox / resize_mask：矩形、画笔、橡皮选区
    - inpaint：内容感知修复（Telea / NS / ShiftMap）
    - add_text_watermark / add_logo_watermark：右下角文字或 Logo 水印
    - match_mask_template / place_mask：可选的模板匹配定位

test_core.py
    自测脚本，会生成一张带“仅供测试 12345”水印的合成图，
    测试去水印、模板匹配、文字/Logo 加水印，输出到 test_out 文件夹。
    运行：python test_core.py

requirements.txt
    Python 依赖版本。

使用说明.txt
    给最终用户看的操作说明。

效果对比.png
    去水印前后效果对比图。

六、关键实现说明
----------------
1. 去水印
   - 用户在样图上画矩形或涂抹，生成单通道 mask。
   - 批量处理时把 mask 缩放到目标图；同尺寸图片最准确。
   - 修复前把 mask 向外膨胀 grow 像素，盖住水印抗锯齿边缘。
   - 只对 mask 外接矩形附近区域做 inpaint，避免整张大图计算过慢。
   - Telea：速度快，适合大多数小面积水印。
   - ShiftMap：OpenCV xphoto 的纹理修复，速度稍慢，复杂背景可尝试。
     注意 xphoto 的 mask 语义与 cv2.inpaint 相反：非零=有效区域，
     所以代码里传入了 bitwise_not(mask)。
   - 修复结果用羽化边缘融合回原图，减少接缝。

2. 加水印
   - 文字水印使用 Windows 微软雅黑/黑体，自动字号或指定字号，
     支持颜色、透明度、边距，默认右下角。
   - Logo 水印按宽度比例缩放，支持透明度、边距，位置固定右下角。
   - 文字和 Logo 都存在时优先使用 Logo。

3. 批量与输出
   - 只处理 jpg/jpeg/png/bmp/webp/tif/tiff。
   - 输出到所选文件夹下的“去水印”或“加水印”子文件夹。
   - 勾选“包含子文件夹”时保留相对目录结构。
   - 原图不修改、不删除、不覆盖。
   - 重名输出自动追加 _1、_2，不会覆盖已有文件。
   - JPEG 默认质量 95；尽量保留 EXIF/ICC。

4. 模板匹配（可选）
   - 以样图上 mask 的外接矩形为模板，在每张目标图中用
     TM_CCORR_NORMED + mask 查找，再放置 mask。
   - 适合水印位置每张不同、但样式固定的情况。
   - 背景复杂时可能误匹配；找不到时自动回退到固定位置 mask。
   - 模板匹配只影响批量处理，预览仍按固定位置显示。

七、已知限制
------------
- 这是传统内容感知修复，不是 Photoshop 的 AI 生成式填充。
  水印面积大、背景纹理复杂时，修复区域可能模糊或有涂抹感。
- 图片尺寸差异很大时，固定 mask 按比例缩放可能对不准；
  建议同尺寸批量处理，或使用模板匹配。
- 模板匹配在重复纹理、纯色背景上可能误匹配，建议先处理一张检查。
- 带透明通道的 PNG 输出会转为 RGB，透明区域会变成白色/背景色。
- ShiftMap 为实验性选项，矩形大选区可能产生纹理拖影。
- 超大图片、超大文件夹会占用较多内存和时间，建议先小批量试跑。
