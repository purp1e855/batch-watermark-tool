批量水印工具 使用说明
======================

一、运行
  双击「批量水印工具.exe」即可，不需要安装 Python。
  系统要求：Windows 10 / 11 64 位。

二、去水印
  1. 点右上角「选择文件夹」，选择放着原图的文件夹。
     也可以直接把文件夹从资源管理器拖进软件窗口。
  2. 软件会自动把第一张图作为样图；也可以点「加载样图…」自己选一张。
  3. 在样图上框选水印：
     - 矩形：按住左键拖一个框，把水印完全盖住；
     - 画笔：按住左键涂抹水印；
     - 橡皮：擦掉画多的选区。
     红色区域就是会被修复的范围，尽量贴紧水印，不要框到不想动的地方。
     画布上方有「适应窗口 / 放大 + / 缩小 −」，鼠标滚轮也可以缩放。
     放大后左键仍然是画选区；要移动图片，点「移动」工具后用左键拖动，或直接按住右键拖动。点「适应窗口」回到全图。
     点「适应窗口」恢复居中。
  4. 如果每张图的水印位置不一样，勾选「使用模板匹配」；位置固定就不用勾。
  5. 先点「预览去水印效果」看样图效果，满意后点「开始批量去水印」。
  6. 结果写到原文件夹下的「去水印」子文件夹，原图不会改动。
     如果勾选「包含子文件夹」，会保留原来的目录结构。

三、加水印
  1. 选择文件夹。
  2. 在「加水印」页填写文字，设置字号（0=自动）、颜色、不透明度、边距。
  3. 也可以选择 Logo 图片，Logo 会优先于文字使用。
  4. 点「预览加水印效果」，再点「开始批量加水印」。
  5. 结果写到原文件夹下的「加水印」子文件夹，原图不会改动。
     水印固定在右下角。

四、输出目录 / 权限问题
  - 默认输出到原图文件夹下的「去水印」或「加水印」子文件夹。
  - 如果提示「拒绝访问 / WinError 5 / Permission denied」：
    1. 点窗口下方的「输出目录」；
    2. 选一个确定可写的位置，例如 E:\水印输出；
    3. 再点开始。软件会在该目录下自动创建 去水印/加水印 子文件夹。
    也可以在弹出的询问框里点「是」，软件会自动改用建议目录并重试。
  - 提示里的 `\` 是 Windows 正常路径分隔符，`/` 和 `\` Windows 都能识别，
    不是报错原因；报错原因是那个位置没有写权限。
  - 「默认目录」按钮可以恢复为原图文件夹。
  - 仍失败时，检查 Windows 安全中心 → 病毒和威胁防护 → 勒索软件防护
    → 受控文件夹访问，把本软件加入允许；或把图片文件夹换到非桌面/非系统盘再试。

五、说明
  - 去水印是本地图像修复（inpaint），不是联网 AI，不消耗 token。
  - 同一张图反复执行会生成 _1、_2 等文件名，不会覆盖已有结果。
  - 选区边缘建议留 2 像素扩展（默认已填 2），可以盖住水印毛边。
  - 批量处理时窗口不要关闭；可点「取消」停止。
  - 处理大图或数量多时会花一些时间，建议先用一张图预览确认效果。
  - 请只处理自己有权编辑的图片。
